# Hani Sri Burugupalli — Personal Portfolio

A high-performance, responsive portfolio web application engineered for **Hani Sri Burugupalli** — AI/ML Developer & Full Stack Developer.

Built with **React 19**, **Vite**, **Tailwind CSS v4**, **Framer Motion**, and **AOS**.

---

## 🚀 Key Features

- **Hero Video & Poster Integration**: Features custom animated video loop with responsive fallback poster, play/pause reel controls, and smooth cross-fading.
- **Water-Filling Preloader**: High-aesthetic branded preloader that dynamically waits for the video ready state before fading away.
- **Interactive ID Badge**: Floating employee-style ID badge with lanyard cord, metal clip, and 3D hover physics with drop-bounce entrance animation.
- **Scroll-Linked Process Pipeline**: Interactive 5-step tag architecture tracking scroll progress along an SVG dashed path with active illumination.
- **Featured Projects Showcase**: Accommodates 7 verified applications (MedLingo, AI JobMatch, SmartRide, SkillBridge AI, Finora, SchemePath, LibraryHub) with flagship glow highlights, categorized tags, and direct demo links.
- **Interactive Lightbox Certificate Gallery**: Modal previewer supporting both high-resolution image credentials and PDF certificates with full-screen view and verification links.
- **Research Experience & Academic Credentials**: Verified NIT Tiruchirappalli ML Research Internship (supervised by Dr. Vinay Raj) and SASI Institute of Technology & Engineering B.Tech curriculum.
- **Crimson Cursor Particle Field**: Ambient particle dynamics that trail mouse velocity and create subtle crimson glow illumination.
- **Full Responsiveness**: Seamless across mobile, tablet, laptop, and 4K desktop viewports.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + Vite 8
- **Styling**: Tailwind CSS v4 + Custom Keyframes
- **Animations**: Framer Motion 12 + AOS (Animate on Scroll)
- **Forms**: Dual-mode Contact Form with direct `mailto:` fallback & EmailJS compatibility
- **Icons**: Custom inline SVGs & Feather icons
